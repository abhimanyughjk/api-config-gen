// ABOUT

What is api-config-gen?

api-config-gen is a browser-based developer tool that auto-generates API configuration files and HTTP client connection code for any API endpoint or popular cloud service.

Stop rewriting the same .env scaffolds and HTTP client boilerplate. Pick a provider, fill in your details, choose a format — get production-ready output instantly.

Everything runs client-side. Your API keys never leave your browser.

// FEATURES

What's Inside

01

18+ API Presets

Auto-fills base URL, auth type, and env var names for OpenAI, Stripe, Supabase, Firebase, AWS, GCP, Razorpay and more.

02

7 Output Formats

Generate .env, JSON, YAML, TOML, JavaScript module, Python dict, or Go struct — whichever fits your stack.

03

Connection Snippets

Boilerplate HTTP client code for Fetch, Axios, Python requests, Go net/http, PHP cURL, and Ruby Net::HTTP — reads from your config.

04

All Auth Types

Bearer, API Key (header/query), Basic Auth, OAuth2, and JWT — with correct headers auto-generated per auth type.

05

One-Click Export

Copy output to clipboard or download the file with the correct extension and filename for your project.

06

Zero Dependencies

Pure HTML + CSS + JS. No npm, no build step, no framework. Clone and open index.html — it just works.

// DOCS

Quick Start

1

Clone the repo

git clone https://github.com/abhimanyughjk/api-config-gen.git
2

Open in browser

open index.html

Or use VS Code Live Server extension.

3

Select provider & configure

Choose a preset or enter a custom URL. Set your auth type, key, timeout, and retry options.

4

Generate & copy

Pick output format, click Generate, then copy to clipboard or download.
